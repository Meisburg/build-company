# Plain-English glossary

| Project term | Plain meaning |
| --- | --- |
| Bot system | The app or service where your bots live, such as Grok Bot or Hermes. |
| Bootstrapper | The first bot that interviews you and sets up the rest of the team. |
| Chief of staff | The bot that keeps track of the company and coordinates work. |
| Shared context | The files every bot can read so they have the same information. |
| Work note | A short message that says what was requested, what was done, and what happens next. |
| Evidence | Information that supports a decision: a link, customer note, test result, or screenshot. |
| First small version | The simplest useful version of a product. Often called an MVP. |
| Safe copy | A separate copy where a bot can make changes without affecting the live product. |
| Routine | A repeating task, such as a daily summary or weekly check. |
| Review | A human or bot checks work before it is shared or put into use. |
