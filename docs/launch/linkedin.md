# LinkedIn launch post

I watched the three-day Grok Bot Galaxy livestream, where a small team built a
company in public—from finding an idea to researching customers, building a
first version, launching it, and learning from feedback.

I saved the transcripts and turned the useful operating pattern into
**BuildCompany**: an open, vendor-neutral starter kit for building a company
with AI bots.

The idea is simple:

1. Start with one bootstrap bot.
2. Say, “Let’s build a company.”
3. Let it interview you about your idea.
4. Let it recommend the smallest useful team.
5. Approve the plan, then create the specialist bots.

BuildCompany includes plain-language role instructions, shared company files,
work-note formats, safety boundaries, and a workflow from discovery to launch.

It began with Grok Bot, but the workflow is designed to work with Hermes Bot
Mode, OpenBot, or any other bot system that supports named agents and shared
instructions.
