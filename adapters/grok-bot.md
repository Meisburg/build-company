# Grok Bot adapter

This is a platform-specific translation of the portable model. Create a chief
bot that owns the company brief and delegates to specialist bots. Add
connectors only for systems a role needs, and give implementation bots a
repository or cloud-agent workspace with review gates.

Useful routine shapes include a daily brief, evidence or feedback scan, metrics
report, and weekly self-improvement proposal. Keep each routine bounded and
report-only until a human approves the action path. For software, prefer small
PRs, independent verification, and human merge approval.

The public Grok Bot Galaxy material describes bots working in parallel across
tools and roles; this guide preserves that workflow without undocumented API or
permission assumptions. Confirm current product behavior before connecting
accounts or granting write access.

Reference: [Grok Bot Galaxy](https://x.ai/galaxy).
