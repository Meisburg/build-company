# Generic adapter

Create one named profile per selected role. Give each profile its role card, the
company brief, and links to shared records. Use direct messages for handoffs;
use a group only for coordination and summaries. Schedule only read/report
routines until the team has earned trust.

If the runtime has no durable shared files, maintain a manually synchronized
brief and treat chat history as transient. If it has no worktree or PR support,
keep implementation drafts outside production and require a human to apply them.
Map every runtime feature against `docs/adapter-contract.md`.
